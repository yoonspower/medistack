# MediStack v1.2 relation 확장 — 릴리스 노트

날짜 2026-06-14 · 베타(참고정보) · published/clinical_reviewed = false 유지

## 무엇이 바뀌었나

식약처 허가사항에 근거가 확인된 **약-영양소 참고정보 14건**을 추가했습니다. 항생제·골다공증약·이뇨제를 복용할 때 일부 영양소(아연·철·마그네슘·칼륨)의 흡수·상태에 영향이 있을 수 있다는 **참고 정보 카드**가 더 많은 약에서 표시됩니다.

- **항생제(플루오로퀴놀론·테트라사이클린) × 아연** — 같은 시간 복용 시 항생제 흡수가 줄어들 수 있어 시간 간격 안내. (레보플록사신·시프로플록사신·오플록사신·목시플록사신·독시사이클린·미노사이클린)
- **골다공증약(리세드론산·이반드론산) × 철·마그네슘** — 기존 칼슘 안내에 철·마그네슘 참고 정보 보강.
- **이뇨제(클로르탈리돈·인다파미드) × 칼륨·마그네슘** — 칼륨 상태 확인 안내(칼륨은 임의 보충 위험 → 상담 권고). 신규로 검색 커버됨.

모든 카드는 "복용 판단이 아니라 상담 준비용" 톤을 유지하며, 제품 추천·구매·복용 지시는 없습니다.
