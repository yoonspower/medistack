## 0. 한 줄 결론

**PPI×칼슘(흡수) relation 은 신규 작성 불가 — draft 도 만들지 않는다.** 22품목 허가사항 어디에도 "PPI가 칼슘 흡수를 저해"하는 상호작용이 **없다(0/22)**. 게다가 이 복합제의 침강탄산칼슘은 **영양 칼슘이 아니라 위산을 중화하는 완충/제산 성분**이라, 칼슘 흡수 카드는 *"칼슘을 더 먹어라/칼슘이 흡수 안 된다"* 로 **오독될 위험이 높다**.

→ **신규 relation 판정 = reject** (테마가 허가사항 맥락과 어긋남). **18건 표시 = name_only 유지(hold).** Task 4(draft relation 작성) 게이트 **미충족 → draft 미작성.**

## 2. source 확인 결과 (허가사항 22품목)

재현: `python3 scripts/verify_ppi_calcium_combo_sources.py`. 원증거: `data/ppi_calcium_source_verification_v1_1.csv`.

| 검증 항목 | 결과 | 의미 |
|---|---|---|
| **PPI×칼슘(흡수) 상호작용 신호** | **0 / 22** | 허가사항에 "PPI가 칼슘 흡수 저해/감소" 진술 **없음** |
| 골절(fracture) 언급 | 22 / 22 | "해외 역학연구 보고 가능성·고용량/장기" = **임상 위험 진술**(상호작용 아님) |
| 침강탄산칼슘 = 제산/완충 규정 | 18 / 18 복합제 | "약알칼리성 약물로서 **위산을 중화**" — 영양 칼슘 아님 |

### 2-1. 핵심 증거(허가사항 원문 인용)

- **칼슘 = 완충제**: *"침강탄산칼슘 : 약알칼리성 약물로서 위산을 중화시켜 위내 산도를 감소시킨다."* (전 복합제 공통)
- **약동학상 칼슘 흡수는 제품 목적이 아님**: 복합제 vs 단일 PPI 위산도 감소분율이 **사실상 동등**(예: 라베가드 74.75% vs 라베프라졸 단일 76.05%) — 칼슘은 즉시 중화용 완충 성분.
- **라벨의 칼슘 상호작용은 전부 "칼슘 성분 자체"의 작용** (PPI×칼슘이 아님):
  - *"침강탄산칼슘 : 테트라사이클린계 항생물질의 흡수를 저해 … 병용투여하지 않는다"* (= 기존 relation 7·26 칼슘×테트라사이클린 패턴, 방향 반대)
  - *"흡착작용 또는 … pH상승에 의해 병용약물의 흡수·배설에 영향"*
  - *"고용량 복용에 의해 고칼슘혈증, 알카리증 … 우유 알칼리 증후군 … 신결석"* (= 칼슘 과량의 자체 이상반응)
- **PPI 쪽 신호는 B12·마그네슘뿐**: *"저염산증/무위산증에 의해 비타민 B12(시아노코발라민) 흡수장애"*, *"저마그네슘혈증"* — 이미 relation 32/33(라베프라졸), 36/37(란소프라졸)로 라이브 반영됨. **칼슘 아님.**

### 2-2. 판정 — 왜 `reject`(`missing` 아님)

본 리포의 source gate 는 **허가사항 우선**이며, 문헌만 있고 허가사항에 없으면 채택하지 않는다(H2×B12 = `missing` 선례, `MediStack_relation_source_verification_atier.md` §3).

- **relation 테마(일반): `missing`** — PPI가 탄산칼슘 흡수를 줄인다는 약리 가설은 문헌상 존재하나(저산성→탄산칼슘 용해↓; 그래서 PPI 복용자에 구연산칼슘 권장) **한국 허가사항 22품목에 미기재**. H2×B12·스타틴×CoQ10 과 같은 "문헌 전용·source gate 미통과" 성격.
- **이 18건에 적용: `reject`** — 단순 미기재(missing)를 넘어, 허가사항이 칼슘을 **완충/제산 성분으로 명시**한다. 즉 칼슘 흡수 카드의 전제(칼슘=흡수 대상 영양소)가 **제품 맥락과 어긋난다**. → 분류 정의상 `reject`("테마가 허가사항 근거와 어긋남")가 `missing` 보다 정확.

> `data/ppi_calcium_combo_review_v1_1.csv` 18행 전부: `source_status = missing(허가사항 0/18)`, `decision = reject(신규 relation 불가) + hold(name_only 유지)`, `risk_level = high`.

## 4. 오도 위험 분석 — C 가 A 보다 보수적이어야 하는 이유

PM 이 지적한 대로 C 는 공존 성분이 **relation nutrient(칼슘) 그 자체**라 A(공존=비타민D3)보다 위험하다. 확인된 위험:

1. **"칼슘 추가복용" 오독**: 칼슘 흡수 저해 카드 → 사용자가 "칼슘 보충제를 더 먹어야겠다"로 받아들일 수 있음(영양제 추천 앱 아님 원칙 위배 소지).
2. **제품 구성과의 모순처럼 보임**: 제품에 칼슘이 들어있는데 "칼슘 흡수 안 된다"는 카드가 뜨면 내부 충돌처럼 오인.
3. **칼슘의 실제 역할 은폐**: 이 칼슘은 흡수용이 아니라 **위산 중화 완충제** → 흡수 프레임 자체가 부정확.

→ 따라서 *설령* 향후 source 정책이 문헌을 허용하더라도, **이 18건(완충형 복합제)에 칼슘 흡수 카드를 붙이는 것은 별개로 부적합**하다.

## 5. Task 5 — C 통합 최종 권고

PM 제시 4지선다 매핑:

- **신규 PPI×칼슘 relation 작성 여부 → D**(relation 구조상 부적합 / 허가사항 출처 없음 / 완충제 오도). **장기 보류·금지. 자동 flip 후보에서 영구 제외 권고.**
- **18건 표시 → A**(현행 name_only 유지가 오늘의 안전 기본값).

다만 본 검증으로 **기존 검토의 3순위 전제가 부분 정정**됨 — 칼슘이 완충제임이 라벨로 확정되어, C 의 전환 경로가 "신규 relation 필요"(달성 불가)에서 다음 **PM 결정 옵션**으로 바뀐다:

| 옵션 | 내용 | 트레이드오프 | 판단 |
|---|---|---|---|
| **(가) name_only 영구유지** | C 18건 현행 유지 | 가장 보수적·무위험. 복합제 검색 시 품목명만. | **오늘 기본값.** |
| **(나) B/D 완충 배너 트랙으로 재분류** | C 를 B(라베+탄산수소나트륨)와 동일 처리 — PPI basis 로 ×B12/×Mg 카드 + 복합제 배너, **신규 relation 0** | 칼슘=완충제라 B 와 기능 동일. 단 기존 검토의 "PPI↔탄산칼슘 흡수 상호작용 미표현=부분정보 불완전" 우려가 남음(배너가 '다른 성분 정보 미포함'으로 고지하긴 함). | **PM 승인 필요. 오늘 실행 안 함.** |

> 권고: **오늘은 (가) 유지.** (나)는 B/D 와의 형평·인프라 재사용 측면에서 합리적 후보이나, "완충 복합제에 칼슘 흡수 미표현을 배너 고지로 갈음해도 되는가"는 **정보 완전성·오도 회피의 정책 판단**이므로 PM 결정 사항으로 남긴다. **라이브 통합은 PM 승인 없이 하지 않는다.**

## 6. 적대적 검증 요약 (독립 반증 시도)

별도 세션이 본 결론을 반증 시도 + 리포 정책 정합성 점검:

- claim(a) 허가사항 출처 없음 → **CONFIRMED** (H2×B12 선례 동일, 22/22 신호 0, source gate=허가사항 우선).
- claim(b) 골절=임상위험 진술이라 금지 → **CONFIRMED** (CLAUDE.md §1 위험확정·임상판단 금지).
- claim(c) C≈B/D, 배너 트랙 가능 → **CONFIRMED(단서부)**: 배너는 basis(PPI) 카드만 노출하므로 칼슘 relation 은 안 뜸. 단 "흡수 상호작용 미표현=불완전" 우려가 남아 **tier-3/PM 결정 버킷**이 맞음(기존 검토와 모순 아님).
- "reject vs missing" → **reject 가 더 정확** (missing=단순 미기재 / reject=칼슘이 완충제로 명시되어 테마가 맥락과 어긋남).
- 라벨에 숨은 채택가능 relation? → **없음**. 탄산칼슘 자체 상호작용(테트라사이클린·고칼슘혈증)은 약-영양소 모델 범위 밖, 골절은 임상판단.

→ 결론 변경 없음. **신규 relation reject · 18건 name_only 유지 · PM 결정 옵션(가)/(나) 제시.**
