## 2. 보류 결정 요지

DF01–DF05 는 **`source_confirmed` + 적대적 검증 통과** 상태로 **근거 자체는 유효**하다(허가사항 이상반응/부작용란에 약 자체가 저칼륨혈증·칼륨손실을 유발한다는 직접 listing 확인). 그럼에도 이번 라운드 **라이브 승격하지 않고 PM 승인 후보로 보관**한다.

이유:

1. **장기·고용량 맥락 의존.** 스테로이드(DF01–03)의 칼륨 영향은 **전신·장기·고용량 사용** 맥락의 부작용이고, 이뇨제(DF04–05)는 **전해질 소실** 기전이라 사용 용량·기간에 따라 임상적 의미가 달라진다. 현재 draft 문구("상태에 영향이 있을 수 있어, 상태 확인이 필요할 수 있습니다")는 톤상 안전하나, **용량·기간 맥락이 빠져 있어** 일반 단기 사용자에게 과·소 해석될 여지가 있다.
2. **문구를 더 신중히 다듬어야 함.** §3 의 재검토 권장 문구(장기·고용량 맥락 한정)를 반영한 뒤 승격하는 것이 톤·정합 측면에서 안전하다.
3. **PM/임상 검토 우선.** 칼륨은 안전정책상 가장 민감한 영양소(임의 보충 위험)라 승격 전 PM/clinical reviewer 트랙 점검을 거친다(§5).

> 리오티로닌×칼슘/철분(DF06/DF07)은 **흡수·복용 간격** 맥락(separation)이라 용량·기간 의존도가 낮고, 칼륨 안전정책과 무관해 이번에 먼저 승격됐다. DF01–DF05 는 그와 별개 트랙으로 보류한다.

## 4. 정책 유지 (불변)

승격 시점이 와도 아래는 **변하지 않는다**(보류 중에도 동일).

- 각 행 `potassium_safety_card = true` · `product_link_allowed = false` 유지(HCTZ id19 / 클로르탈리돈·인다파미드 D11/D13 동일 안전정책 승계).
- `published = false` · `clinical_reviewed = false` 유지(CLAUDE.md §1 천장 = verified_reference).
- 제품 링크·구매 버튼·제휴 UI·제품 예시·제품 필드 **0**(CLAUDE.md §1 제품/제휴 금지).
- 칼륨 고지는 `potassium_safety_card === true` 플래그 기준 렌더(nutrient 문자열 매칭 금지, CLAUDE.md §4).
- evidence_level = high(이상반응/부작용 직접 listing 확인). 단, **장기·고용량 맥락 부작용**임을 §3·§5에서 명시.

## 5. 승격 전 PM / 임상 체크리스트

PM 승인 + (가능 시) clinical reviewer 트랙에서 아래를 통과해야 승격한다. 하나라도 미충족이면 **보류 유지**.

- [ ] **용량·기간 맥락 문구 적절성.** §3.1 재검토 권장 문구(장기·고용량 맥락)와 현재 draft 문구 중 채택안 확정. "장기 복용 시 칼륨이 빠집니다" 같은 **단정 금지**, "칼륨 보충하세요" 같은 **권유 금지** 재확인.
- [ ] **기전 차이 반영.** 스테로이드(DF01–03)는 **이상반응(부작용) listing** 기반(미네랄코르티코이드 작용), 이뇨제(DF04 탄산탈수효소억제 / DF05 루프)는 **전해질 소실** 기전 — 문구가 둘을 동일 톤으로 묶되 과장 없이 표현하는지 확인.
- [ ] **칼륨 안전정책 승계 확인.** `potassium_safety_card=true`·`product_link_allowed=false`·`disclaimers.potassium_notice` 정합, management 문구 무변경.
- [ ] **적대적 검증 재확인.** 5건 verdict `confirm` 유지 여부, 인용(저칼륨혈증/칼륨손실 동거어)이 **첨가제/조성이 아니라 이상반응·부작용 문맥**인지 재확인. 라벨 변경 가능성 있으면 itemSeq 재fetch.
- [ ] **금지어 게이트.** 채택 문구를 `scripts/validate_forbidden_phrases_v1_2.py` 로 스캔(식약처 승인/법적 문제 없음/약사 검수 완료/추천 영양제/복용하세요/치료/예방/구매/제휴 등) — 위반 0 확인.
- [ ] **published/clinical false 유지** 및 라이브 데이터 무변경(승격은 별도 통합 단계).
