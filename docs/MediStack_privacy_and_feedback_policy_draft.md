# MediStack — 개인정보 / 피드백 정책 초안 (DRAFT)

> 작성일: 2026-06-13. **초안(DRAFT) — 법률 검토 전이며 법적 효력·합법성 보장이 아니다.** 공개 전 전문가 검토로 확정. 게이트 = `MediStack_public_release_legal_safety_checklist.md`.
> **피드백 폼 구현은 본 세션 범위 밖** — 정책/설계만 작성. 폼 공개는 게이트 STOP #6(개인정보/건강정보 수집 차단 설계) 충족 후.

## 1. 호스팅 / 로그 고지 (정직)

- MediStack은 **GitHub Pages(정적 호스팅)** 로 배포된다(`yoonspower.github.io/medistack`). 정적 사이트라도 **호스팅 제공자인 GitHub** 가 접속 과정에서 **IP 주소·브라우저(User-Agent)·접속 시각 등 접속 로그**를 수집할 수 있다(GitHub의 정책에 따름).
- **MediStack 자체는 별도의 백엔드 서버나 자체 접속 로그를 운영하지 않는다.** (현재 구조: 정적 파일 fetch만, 서버 측 사용자 로깅 없음.) 향후 자체 서버/분석 도구를 도입하면 본 정책을 갱신한다.
- MediStack은 **쿠키 기반 추적·광고 추적·제3자 분석을 사용하지 않는다**(현 구조 기준). 도입 시 별도 동의·고지 필요.
- **국외 이전 가능성(법률 검토 필요)**: GitHub은 **미국 소재 호스팅 제공자**이므로, 접속 과정에서 발생하는 IP·User-Agent 등은 사실상 **국외(미국)로 이전**될 수 있다. 개인정보보호법상 개인정보의 국외 이전은 별도 사안(고지·근거 등, 제28조의8 계열)으로 다루어지므로, **일반 공개 전 국외 이전 해당성·의무를 법률 검토에서 확인한다(DRAFT).**

## 2. 입력 데이터 (검색)

- 검색창 입력은 **약명·영양소명 확인**을 위한 것이며, 서버로 저장·전송되지 않는다(클라이언트 측 검색).
- **개인정보·건강정보를 입력하지 마십시오** — 증상, 질환명, 복용 이력, 주민등록번호, 연락처, 처방전 사진 등.

## 3. 피드백 (구현 시 정책 — 본 단계는 설계만)

피드백 동선을 추후 도입할 경우 다음 정책을 강제한다:

- **약명 누락 제보만 받는다** (예: "○○약이 검색되지 않습니다").
- **금지 입력**(수집 차단 설계 필수): 증상·질환·복용 이력·진단명·주민등록번호·연락처·이메일·처방전/약 사진 등 **개인정보·건강정보**.
- 입력 폼은 자유서술 건강정보를 **수집하지 않도록 설계**(필드 제한·안내 문구·가능하면 자유입력 최소화).
- **건강정보가 수집될 가능성이 있는 형태라면**, 별도의 **개인정보 처리방침 + 사전 동의(민감정보 처리 동의 포함)** 가 필요하다 — 이 경우 폼 공개 전 법률 검토 필수.
- 피드백 제출 채널(이메일/이슈/폼)별로 어떤 제공자가 데이터를 보유하는지 고지한다(구현 단계에서 구체화).

## 4. 미성년자

- 미성년자의 개인정보·건강정보 입력을 금지하며, 보호자 지도하에 사용한다(이용약관 §7 연동).

## 5. 정책 변경

- 본 정책은 변경될 수 있으며, 변경 시 서비스 내 고지한다(고지 방식은 구현 단계 정의).

## 부록 A — 수집/미수집 요약(현 구조)

| 항목 | 현재 | 비고 |
|---|---|---|
| MediStack 자체 서버 로그 | **없음** | 정적 호스팅, 백엔드 없음 |
| GitHub(호스트) 접속 로그(IP/UA/시각) | 수집 가능 | GitHub 정책 — 고지 필요 |
| 쿠키/광고/제3자 분석 | **없음** | 도입 시 동의·고지 필요 |
| 검색 입력 서버 전송/저장 | **없음** | 클라이언트 측 |
| 피드백 폼 | **미구현** | 도입 시 약명 누락만·건강정보 차단·필요 시 처리방침+동의 |

**알려진 미결 항목(공개 전 확정):** 정식 개인정보 처리방침에는 **개인정보 처리자(운영 주체)의 신원·연락처·개인정보 보호책임자**를 기재해야 하나, 본 초안에는 **미기재** — 법률 검토/공개 단계에서 확정한다.

> 본 초안은 법적 효력·합법성 보장이 아니며, **전문가 검토 전 공개 금지**. 건강정보 수집 가능성이 있으면 별도 처리방침/동의 없이는 피드백 폼 공개 금지(게이트 STOP #6).
