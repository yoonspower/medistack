## 1. deferred 112 실측 재집계 (2026-06-12, read-only)

`data/candidates/bulk_alias_review_queue_v0_5.json` 의 `status=deferred` 112 건 전수 파싱. `ingr_name` 의 성분 구성으로 분류.

| 구성 | 건수 | 칼륨 방향 |
|---|---|---|
| 2성분 **ARB + HCTZ** | 98 | ARB ↑K · HCTZ ↓K → **상쇄** |
| 3성분 **ARB + CCB + HCTZ** | 14 | ARB ↑K · CCB K무관 · HCTZ ↓K → **상쇄** |
| **칼륨보존이뇨제 + HCTZ** (트리암테렌·아밀로라이드·스피로노락톤 등) | **0** | (역전·최고위험 군) |
| **합계** | **112** | |

**distinct 파트너 성분(HCTZ 제외)**: 로사르탄칼륨 · 발사르탄 · 올메사르탄메독소밀 · 칸데사르탄실렉세틸 · 텔미사르탄 · 피마사르탄칼륨삼수화물 · 암로디핀베실산염(CCB). 전부 ARB 또는 CCB.

> 🔑 **핵심 신규 발견**: v0.7 문서가 HCTZ 의 대표 위험으로 지목한 **"칼륨 방향 역전"(K-소실 정보 노출 ↔ 실제 K-보존 제품)** 의 진짜 위험 군 = **칼륨보존이뇨제 복합제는 112 건 중 0 건.** 112 는 전부 ARB(±CCB) 복합제로, ARB 는 칼륨을 **올리지만**, HCTZ 의 K-소실을 **상쇄(완화)** 할 뿐 **순(net) K-증가로 역전시키는 일반적 설계가 아니다**(오히려 이 복합제들이 존재하는 임상 이유가 ARB 로 치아지드 저칼륨혈증을 완화하는 것). 즉 위험 프로파일이 v0.7 의 "일괄 제외" 전제보다 **낮다.**

**데이터 품질 메모**: 파트너 성분명에 `올메사르탄메독소밀` 과 오타본 `올메사탄메독소밀` 이 혼재(원천 nedrug 품목명 오기). confirm 단계 정규화 대상. (이 문서에서 수정하지 않음.)

HCTZ canonical(`히드로클로로티아지드`)의 라이브 relation 2건 — `data/medistack_v0.2_beta_export.json`:

| id | nutrient | mechanism | `product_link_allowed` | `potassium_safety_card` | management_ko |
|---|---|---|---|---|---|
| 19 | 칼륨 | depletion | **false** | **true** | "칼륨은 임의로 보충하면 위험할 수 있으므로, 보충 여부는 반드시 의사 또는 약사와 상담하세요." |
| 20 | 마그네슘 | depletion | true | false | "장기 복용 중이라면 정기 진료·복약 상담 시 …문의해볼 수 있습니다." |

- id 19(칼륨)는 이미 **제품링크 차단 + 칼륨 안전카드 + "임의보충 위험·상담 필수" 문구**로 보수적으로 짜여 있다. **사용자에게 칼륨을 보충하라고 지시하지 않는다.** 오히려 자가보충을 경고한다.
- 이 안전장치는 단일 HCTZ 를 가정해 작성됐다(§4 에서 복합제 정확성 평가).

## 3. 칼륨 안전성 분석

### 3-1. 약리 방향
- **HCTZ**(치아지드 이뇨제): 원위세뇨관 Na 재흡수 억제 → **칼륨 소실(저칼륨혈증)**, 마그네슘 소실.
- **ARB(◯◯사르탄)**: RAAS 차단 → 알도스테론 ↓ → **칼륨 보존(고칼륨혈증 위험)**.
- **복합제(ARB+HCTZ)**: 두 작용이 **반대**. 임상적으로 ARB 가 HCTZ 의 저칼륨혈증을 **완화**하도록 설계된 조합. 순효과는 보통 "HCTZ 단독보다 약한 K 소실 ~ 중립".

### 3-2. 위험 시나리오와 실제 노출
| 시나리오 | 성립 조건 | 112 에서 | 평가 |
|---|---|---|---|
| K-소실 정보가 **순(net) K-증가** 제품에 붙음 | 파트너가 강한 칼륨보존(트리암테렌 등) | **0 건** | 해당 없음(빈 군) |
| K-소실 정보를 보고 **자가 칼륨 보충** → ARB 와 합쳐 **고칼륨혈증** | 사용자가 management 경고를 무시 | 잠재 위험 | **management_ko 가 자가보충 금지·상담 지시로 1차 완화.** 잔여 위험 = §4 |
| 염이름 `칼륨` 오인 | 로사르탄**칼륨**·피마사르탄**칼륨** | 다수 | §3-3 |

### 3-3. 염이름 "칼륨" 오인 트랩
- `로사르탄칼륨`, `피마사르탄칼륨삼수화물` 의 "칼륨"은 **ARB 의 짝이온 염**이지 치료용 칼륨도, 칼륨 영양소도 아니다.
- 위험: ① 칼륨 키워드 하이라이트/검색이 약물명을 칼륨 영양소로 오인, ② alias·고지 렌더가 "칼륨 함유"로 오독. → **validator·렌더에서 염이름 칼륨과 nutrient 칼륨을 분리해야 한다**(§6).

### 3-4. 소결
- 진짜 위험 군(칼륨보존 복합제)이 **0 건**이라 v0.7 의 "역전 오도" 우려는 **이 데이터셋에서는 실현되지 않는다.**
- 잔여 칼륨 위험은 **자가보충 오인(§4) + 염이름 오인(§3-3)** 두 가지로 좁혀지며, 둘 다 **고지·validator 로 제어 가능**한 성격이다(임상판단 필요한 antagonism 행과 다름).

## 4. 부분정보 오인 리스크

- 복합제 alias 는 제품 → canonical(HCTZ) 1개로 매핑된다. 112 전부 **relation 보유 성분이 정확히 1개(HCTZ)** → 다중 canonical 충돌 없음(메트/알렌/오메 복합제와 동일 구조).
- 그러나 제품은 성분 2~3개인데 **HCTZ 의 약-영양소 정보(칼륨·마그네슘)만** 보인다. **ARB 가 칼륨을 반대 방향으로 움직인다는 사실은 우리 데이터에 없어 화면에 안 뜬다.**
- **HCTZ 고유의 오인 벡터**: 사용자가 "이 약은 칼륨을 뺀다"만 보고 → (경고를 무시하고) 칼륨 보충 → ARB 와 합쳐 고칼륨혈증. 메트(B12)·알렌(칼슘)·오메(B12·Mg) 복합제의 부분정보는 "정보 누락"에 그치지만, **HCTZ 는 누락된 파트너가 표시된 정보를 반대로 당긴다**는 점에서 한 단계 더 위험하다.
- **완화 현황**: management_ko 가 이미 "임의보충 위험·상담 필수"라 보충을 **지시하지 않는다.** 부분정보 자체는 거짓이 아니다(HCTZ 는 실제로 그 제품에 들어있다). 남는 건 **"이게 이 약의 전부"라는 오인** → 복합제 전용 고지로 닫아야 한다(§5).

## 5. 고지 UX

### 5-1. 이미 라이브인 장치 (v0.7 G2)
- 복합제 배지 + **부분정보 배너**("표시된 정보는 ◯◯ 성분 기준") 가 `is_combination=true` alias 에 렌더된다(메트/알렌/오메가 사용 중).
- `potassium_safety_card=true`(id 19) 는 복합제 여부와 무관하게 칼륨 행에 항상 렌더.
- → **UI 기계장치는 이미 존재**한다. HCTZ 복합제는 이 위에 올라탄다.

### 5-2. HCTZ 가 추가로 필요로 하는 것
기존 배너는 "정보 누락"용이라 **방향 반전**을 알리지 않는다. HCTZ 복합제 칼륨 행에는 **반전을 명시하는 1줄**이 필요하다. 예(문구 초안, 결정 전):

> "이 제품은 복합제입니다. 표시된 칼륨 관련 정보는 **히드로클로로티아지드 성분** 기준이며, 함께 든 ARB(◯◯사르탄) 성분은 칼륨을 **반대 방향(보존)**으로 움직일 수 있습니다. 칼륨은 임의로 보충하면 위험하므로 보충·검사 여부는 반드시 의사·약사와 상담하세요."

- 안전 원칙 준수: 원문(허가사항)에 있는 사실만 사용, 보충 지시 없음, 제품링크 없음, 칼륨 안전카드 유지.
- 이 1줄은 **append-only 플래그**(예: `potassium_combo_notice=true` 또는 partner class 메타)로 데이터에 박고 render 가 분기 — 즉 **앱 UI 변경 동반**(불변규칙 완화 PM 승인 필요, v0.7 G2 와 동일 성격).

### 5-3. 고지 UX 옵션
- **U1 — 기존 배너 + potassium_safety_card 그대로**: 추가 작업 0. 단 방향 반전 미고지 → **부족(비권고).**
- **U2 — 기존 + HCTZ-combo 칼륨 반전 고지 1줄(권고)**: §5-2. 반전을 명시. 앱 render 분기 1개 추가.
- **U3 — 복합제에서 칼륨 행 숨기고 마그네슘만 노출**: 반전 위험 회피하나 **임상상 더 중요한 전해질을 가림** + 칼륨 안전카드 무력화 → **비권고.**
