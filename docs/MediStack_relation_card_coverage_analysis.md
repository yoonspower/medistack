## 6. 제조사 / 출처 분포

- **제조사: relation_card 558 전건 `company_name` = null.** relation_card 는 alias 경로(`internal.medistack_v0_3_aliases`) 유래라 제조사 메타가 비어 있다. 반면 name_only(17,022)는 nedrug 샤드 직수집이라 제조사가 채워져 있다 → **제조사별 분석은 현재 relation_card 만으로 불가**(향후 nedrug 조인 필요).

## 8. 사용자 체감 가치 평가

- **검색 가능량: 높음** (17,580 품목명 — 사실상 대부분의 국내 정제/캡슐 검색 시 "이름은 나온다").
- **참고정보 표시량: 낮음** (3.17%). 대부분 검색은 name_only 로 귀결.
- **체감 강점**: 등록된 13성분(항생제·메트포르민·HCTZ·알렌드론산·PPI·레보티록신)을 검색하면 출처 있는 참고정보가 즉시 붙는다 — 품질·안전선은 견고.
- **체감 약점(핵심)**: 등록 성분이 **항생제 위주**라, "내가 매일 먹는 약"(스타틴·혈압약 ARB 단일·당뇨 외 대사약·역류성식도염 PPI 타 성분·전립선·통증)을 검색하면 정보가 안 붙을 가능성이 높다 → **인기약 커버리지 미확인**이 가장 큰 불확실성.
